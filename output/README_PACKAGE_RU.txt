1. ЧТО ИЗМЕНИЛОСЬ ВО ВТОРОЙ РЕДАКЦИИ

output/Anilite_NMR_draft_ru.docx — редактируемая русская рукопись с английской аннотацией, численными порошковыми расчетами, анализом затухания эха, двумя рисунками, таблицами, нативными формулами и литературой. Текущая верстка содержит 9 страниц, 2 таблицы, 2 рисунка, 5 формул и 7 комментариев Word. Текст и результаты пересмотрены после пояснений автора и изучения диплома и ранних рукописей.

Автор подтвердил, что ЯКР и ЯМР исследовались на том же размолотом, закрепленном неориентированном порошке. В дипломе документированы частицы около 30 мкм и фиксация в эпоксидной смоле; в рабочем конспекте указан Stycast. Предпочтительной ориентации частиц в порошковой модели нет.

Историческая последовательность обозначений — первоначально geerite, затем digenite в поздней публикации, а по повторной рентгенографии anilite — отражена в обсуждении. Сам отчет повторного XRD в предоставленных материалах пока отсутствует; для публикации его следует приложить. Общность исследованного материала уже подтверждена автором и не оставлена как нерешенный вопрос.

Узкий сигнал металлической меди датчика исключен из целевой функции подгонки интервалами ±0.12 МГц около 75.941 и 81.346 МГц. Это маскирование при оценке параметров образца, а не экспериментальное вычитание записанного отдельно спектра пустого датчика.

Выполнены реальные расчеты порошковых спектров и условные оценки η и νQ. Обнаружены сопоставимые решения, особенно неоднозначные для первой слабой группы. Эти оценки не представлены как единственные физические константы Cu1–Cu5.

Для T2a принята единица TwoTau = мкс по экспериментальному контексту автора и диплому; определено t = 2τ. Из модуля комплексного интеграла эха получено эффективное время около 0.955 мс и β около 1.255. Это параметры огибающей и чувствительность к модели, а не статистический доверительный интервал или доказательство отдельного микроскопического механизма.

3. КРАТКИЙ ИТОГ РАСЧЕТОВ

Совместно описаны две серии интегралов эха 20 и 500 мс, по 245 немаскированных точек. Основные νNQR взяты из собственных результатов диплома 2009: 63Cu 11.97, 15.27, 16.18, 16.96 МГц; набор 2013 проверен отдельно.

В модели центральных переходов с неотрицательным основанием сопоставимые ветви дают η примерно (0.18, <0.01, 0.18, 0.30) и (0.93, <0.01, 0.18, 0.33). В других проверенных семействах значения сдвигаются. Это показывает неоднозначность слабой первой группы и зависимость результатов от принятой модели. Не моделировались полная импульсная последовательность и анизотропный тензор магнитного сдвига.

Для |IntRe+iIntIm| модель A exp[−(t/T2e)^β] дает T2e=0.9547 мс, β=1.2552. Обычная экспонента дает близкое время 0.9450 мс, но больший среднеквадратичный остаток. Подмножества данных в обобщенной модели дают около 0.94–1.00 мс; это проверка чувствительности. Прежний ЯКР имеет масштаб T2 около 0.11–0.17 мс по графику диплома, но относится к иным переходам и нулевому внешнему полю.

4. ВОСПРОИЗВЕДЕНИЕ

Все команды ниже выполняются из корневой папки распакованного пакета. Нужны Python 3.10+, NumPy, SciPy и Matplotlib. В текущем расчете использованы NumPy 2.3.5, SciPy 1.17.0, Matplotlib 3.10.8.

Сначала извлечение и описательная сводка:
python data_analysis/analyze_measurements.py
python data_analysis/summarize_manuscript.py

Затем расчет огибающей:
python relaxation_analysis/analyze_t2.py

Основной порошковый расчет с начала, в порядке зависимостей:
python powder_model/joint_fit.py
python powder_model/refine_exact_joint.py
python powder_model/central_control.py
python powder_model/joint_literature_sensitivity.py
python powder_model/finalize_controls.py
python powder_model/extent_examples.py

Промежуточные библиотеки *.npz при отсутствии будут созданы автоматически. Глобальный поиск и прямое уточнение значительно дольше извлечения таблиц. Сохраненные в пакете JSON позволяют повторно построить итоговую таблицу и рисунок командой python powder_model/finalize_controls.py без повторения всей оптимизации.

Дополнительные старые диагностические семейства и их рисунки воспроизводятся отдельно:
python powder_model/powder_fit.py --set thesis2009 --extended
python powder_model/powder_fit.py --set publication2013
python powder_model/validate_and_plot.py
python powder_model/finalize_results.py

Последняя команда этого дополнительного блока использует уже созданный joint_results.json; ее выходы относятся к промежуточному этапу. Итоговая таблица с префиксом FINAL создается finalize_controls.py.

Структурные кратности:
python research_literature/reproduce_anilite_sites.py

Для сборки DOCX дополнительно нужны python-docx 1.2.0 и Pandoc. После наличия итоговых рисунков:
python draft/build_document.py

Команда читает manuscript_v2.md и powder_results_v2.md и записывает output/Anilite_NMR_draft_ru.docx.
