РАСЧЕТ НЕОРИЕНТИРОВАННОГО ПОРОШКОВОГО ЯМР МЕДИ
Рабочий численный анализ для статьи об анилите, 26 ноября 2026 г.

1. ЧТО ФАКТИЧЕСКИ СДЕЛАНО

Выполнена подгонка широкого ЯМР-отклика двумя изотопами меди, связанного с четырьмя спектроскопическими группами ЯКР. Рассчитаны условные значения асимметрии η, квадрупольного параметра νQ, эффективных зеемановских частот и уширения. Проверены разные ограничения модели, оба периода повторения, маски катушечного сигнала, два набора частот ЯКР и несколько начальных условий оптимизации.

Эта работа показывает, что параметр η можно исследовать по неориентированному порошку. Однако в имеющемся многокомпонентном спектре четыре независимых η не определяются однозначно выбранным семейством моделей. Особенно слабая идентифицируемость обнаружена для группы s1 около 12 МГц ЯКР. Ни один из перечисленных минимумов не объявлен окончательным набором физических констант анилита.

Ниже s1–s4 означают спектроскопические группы по частотам ЯКР, а не структурные позиции Cu1–Cu5.

2. ИСХОДНЫЕ ДАННЫЕ

Для численной целевой функции использована таблица opj_Spec05122016.csv из Anilite.OPJ: две серии интегралов эха с периодами повторения 20 и 500 мс. Обе конфликтующие строки при 81.40 МГц исключены. Не использована мелкая сетка обработанного спектра как набор независимых экспериментальных точек.

В основной подгонке исключены интервалы ±0.12 МГц вокруг 75.941 и 81.346 МГц, соответствующие узким линиям меди датчика. В целевой функции остаются по 245 точек каждой серии. Маска исключает катушечный вклад из оценки параметров образца; данные внутри маски не заменены моделью и не объявлены экспериментально вычтенными. Дополнительно проверены маски ±0.08 и ±0.18 МГц в ограниченной модели с общим η.

Основной набор ЯКР при 4.2 K взят из диплома И. А. Евлампиева «Ядерный квадрупольный резонанс меди в гирите», 2009, стр. 21, и ранней рукописи geerite to digenite.docx:

        s1       s2       s3       s4
63Cu    11.97    15.27    16.18    16.96 МГц
65Cu    11.07    14.13    14.97    15.69 МГц

Набор из Gainov et al., European Journal of Mineralogy 25 (2013), 569–578, DOI 10.1127/0935-1221/2013/0025-2325, проверен отдельно:

63Cu    11.90    15.21    16.26    16.81 МГц
65Cu    11.02    14.10    15.05    15.55 МГц

Частоты разных наборов не смешиваются. Различия обозначений и происхождения этих чисел обсуждаются в записке к диплому. Температурная поправка между 4.2 K и 5 K не вводилась без соответствующих исходных данных.

3. ГАМИЛЬТОНИАН, ПОРОШКОВОЕ УСРЕДНЕНИЕ И ПАРАМЕТРЫ

Для I=3/2 использован гамильтониан в частотных единицах

H/h = −νZ (n·I) + (νQ/6)[3Iz² − I(I+1) + η(Ix²−Iy²)].

Связь с ЯКР: νQ = νNQR / sqrt(1+η²/3), 0≤η≤1. Знак νQ этим анализом не определяется; в расчете использован положительный модуль.

Матрица 4×4 диагонализируется численно для ориентаций направления внешнего поля n в главных осях ГЭП. Ориентационная сетка равномерна по cos(theta) и phi; симметрия позволяет интегрировать один октант. Предпочтительной ориентации, магнитного выравнивания или текстуры в модели нет.

В модели всех переходов учтены все шесть пар энергетических уровней. Вес перехода пропорционален усредненному квадрату матричного элемента поперечного ВЧ-поля:

Wuv = 1/2 [sum_a |<u|Ia|v>|² − |<u|n·I|v>|²].

В контрольной модели оставлен только центральный переход между двумя средними уровнями, а неразрешенное основание представлено неотрицательной линейной функцией частоты.

Магнитный сдвиг в каждом компоненте принят изотропным. Его величина выражается свободной эффективной зеемановской частотой νZ, а не откалиброванным сдвигом Найта. Главные оси и анизотропия тензора K не подгонялись. Для второго изотопа νZ65/νZ63 = 1.0712106566, по изотопному отношению магнитных моментов. Для квадрупольного взаимодействия использованы собственные частоты ЯКР каждого изотопа.

Каждый порошковый профиль свернут с общей гауссовой функцией стандартного отклонения σ. Это феноменологическое спектральное уширение; его нельзя автоматически преобразовать во время спинового эха T2. Относительные амплитуды четырех групп и общий масштаб 65Cu свободны; они описывают зарегистрированный отклик и не являются числом атомов в структурных позициях.

Это модель частот и относительного спектрального отклика. Полная импульсная последовательность, распределение B1, конечная полоса возбуждения, ориентационная зависимость поворотов спинов, T1/T2 и аппаратная частотная характеристика не моделировались. Поэтому модель не является полным расчетом амплитуды импульсного эха.

4. КАК ВЗВЕШЕНЫ СЕРИИ

Целевая функция — сумма квадратов остатков двух серий после деления каждой на ее максимальный немаскированный интеграл: 10291.363927 для 500 мс и 2247.720654 для 20 мс. Число используемых точек одинаковое, по 245. Таким образом, серия 500 мс не получает больший вес только из-за большего абсолютного сигнала.

Эта сумма квадратов не является χ² с известными экспериментальными дисперсиями. Формальные доверительные интервалы, p-значения и статистическая значимость различия минимумов не вычислялись. Остатки содержат систематическую структуру, поэтому погрешность нельзя достоверно получить одним масштабированием ковариационной матрицы оптимизатора.

5. РЕАЛЬНО ПРОВЕРЕННЫЕ СЕМЕЙСТВА

А. Четыре группы с общими η и νZ, общим σ, свободными амплитудами. Для длинной серии по набору 2009 получен η≈0.225, но σ достигает установленной верхней границы 0.25 МГц. Остаются выраженные систематические остатки. Для короткой серии минимум дает η≈0.292. Эти два числа не приняты за измерение единственного η материала.

При слишком узкой катушечной маске ±0.08 МГц в подгонку попадают склоны узкой линии и минимум уходит к η=1 и нижней границе σ. При масках ±0.12 и ±0.18 МГц ограниченный длиннопериодный fit дает близкое η≈0.225. Проверка показывает необходимость явного исключения катушечной линии. Она не доказывает устойчивость каждого отдельного η в более сложной модели.

Б. Для длинной серии разрешены четыре η при общем νZ, а затем четыре самостоятельных νZ. Появляются существенно разные наборы η и корреляции с магнитными сдвигами. Эта проверка демонстрирует, почему общий η нельзя без проверки трактовать как свойство всех Cu-позиций.

В. Совместный fit 20 и 500 мс: общие для обеих серий четыре η, четыре νZ и σ; амплитуды, изотопный масштаб и линейная поправка независимы для серий. Начальные глобальные поиски дали две сопоставимые ветви. После прямого локального уточнения полного H на фактических центрах получены:

Ветвь L:
η = (0.1046, 0.0514, 0.2239, 0.2979);
|63νQ| = (11.9482, 15.2633, 16.0465, 16.7146) МГц;
νZ63 = (76.4050, 75.9487, 75.5830, 76.5037) МГц;
σ = 0.06199 МГц; суммарная нормированная SSE≈0.55101.

Ветвь H:
η = (0.8135, 0.0531, 0.2240, 0.3349);
|63νQ| = (10.8344, 15.2628, 16.0464, 16.6516) МГц;
νZ63 = (76.3244, 75.9504, 75.5439, 76.5138) МГц;
σ = 0.06602 МГц; суммарная нормированная SSE≈0.54188.

Это два найденных локальных решения. Ни одно не доказано единственным глобальным минимумом. Существенно различающийся η1 практически не меняет качество описания. Амплитуда s1 в этой модели заметно меньше амплитуд s2–s4.

У модели всех переходов линейная поправка получается отрицательной: в центре диапазона около −426…−448 a.u. для 500 мс и −56…−58 a.u. для 20 мс. Для интеграла модуля эха ее нельзя называть физическим фоном. Это компенсация широкого основания моделью и обработкой. Поэтому данное семейство используется как проверка чувствительности, а не как завершенная физическая интерпретация интенсивностей.

Г. Контроль: только центральные переходы и неотрицательное линейное основание. После теплых стартов от тех же двух ветвей получены:

Ветвь L:
η≈(0.180, 0.000, 0.182, 0.296);
|63νQ|≈(11.906, 15.270, 16.092, 16.718) МГц;
νZ63≈(76.430, 75.956, 75.607, 76.527) МГц;
σ≈0.0663 МГц.

Ветвь H:
η≈(0.925, 0.003, 0.182, 0.325);
|63νQ|≈(10.559, 15.270, 16.092, 16.669) МГц;
νZ63≈(76.360, 75.959, 75.594, 76.525) МГц;
σ≈0.0674 МГц.

В подгонке контрольного семейства SSE≈0.61653 и≈0.61058 соответственно, различие около 1%. Положительное основание составляет примерно 600 a.u. в серии 500 мс и 130 a.u. в серии 20 мс. Дополнительные значения целевой функции после непосредственного пересчета H на фактических центрах и более плотной сетке приведены в central_exact_validation.json и FINAL_MODEL_COMPARISON.csv. Этот контроль тоже не включает полную импульсную физику.

Д. Чувствительность к набору ЯКР: выполнен теплый старт того же совместного семейства всех переходов с частотами 2013 г. Низкая ветвь дает η≈(0.167,0.0607,0.2153,0.300), высокая сохраняет η1≈0.918 при η2–4≈(0.0588,0.2146,0.3014). Соответствующие νQ и частоты находятся в joint_literature_sensitivity.json. Это сравнение не смешивает два набора и не переносит результат из модели с общим η.

6. ЧИСЛЕННАЯ ПРОВЕРКА

Для предварительного глобального поиска строилась библиотека точных гамильтонианов при 63νZ=75.8 МГц, а профиль затем переносился по эффективному центру. Максимальная ошибка частоты центрального перехода от такого переноса в найденном совместном решении составляет по группам приблизительно 5.7, 2.1, 3.7 и 14.5 кГц. Это меньше шага исходной таблицы 50 кГц, но может влиять на близкие значения SSE.

Поэтому выполнены прямые проверки при фактических νZ и плотностях ориентаций 40×80, 80×160 и 160×320 в октанте. Кроме того, две совместные ветви уточнены непосредственным расчетом H на сетке 80×160, без частотного переноса библиотеки. Числа раздела 5В относятся именно к этому уточнению. Контроль центральных переходов проверен при фактических центрах на 160×320.

В предварительном поиске границы η — 0…1, σ — 0.025…0.25 МГц. Для совместного семейства νZ63 допускается в пределах 74.8…76.8 МГц; найденные центры в эти границы не упираются. Все границы и численные схемы открыто заданы в скриптах.

7. ЧТО МОЖНО ЗАКЛЮЧИТЬ О η

Условно, внутри проверенного изотропного семейства: s2 близка к аксиальной; для s3 получаются η около 0.18–0.22; для s4 — около 0.30–0.34. Для s1 существуют резко разные сопоставимые решения. Это диапазоны различия исследованных моделей, а не статистические доверительные интервалы.

Систематическая неопределенность от тензора магнитного сдвига, возможного остаточного ковеллина (его прежняя линия ЯКР 63Cu около 14.87 МГц близка к s2), реального возбуждения эха и назначения групп структурным позициям не измерена. Введение всех этих степеней свободы без новых ограничений лишь увеличило бы неоднозначность; такие модели не были объявлены выполненными.

Для рукописи корректна формулировка: «Совместная модель неориентированного порошкового спектра и частот ЯКР дает условные оценки квадрупольных параметров и выявляет неоднозначность части назначений; однозначное определение четырех независимых η требует проверки магнитной анизотропии и спектрального отклика». Некорректно формулировать результаты как окончательно измеренные η для Cu1–Cu5.

8. ПРОВЕРЯЕМЫЙ ПРИМЕР О ПЯТОЙ ЛИНИИ И КРЫЛЬЯХ

Отсутствие новых линий за наблюдаемой огибающей ограничивает дополнительные достаточно интенсивные и удаленные резонансы. Оно не требует, чтобы любая новая позиция давала внешние крылья.

Точный расчет для νZ=76 МГц и νNQR=1.5 МГц:

η=0: центральный переход от −9.868 до +5.551 кГц относительно νZ; оба спутника суммарно в диапазоне 74.500–77.500 МГц.

η=1: центральный переход от −14.801 до +7.401 кГц; оба спутника суммарно в диапазоне 74.701–77.299 МГц.

Такой вклад мог бы находиться внутри широкой огибающей групп с νNQR около 12–17 МГц. Это численный контрпример обязательности внешних крыльев, а не назначение пятой позиции анилита. В старом дипломе действительно есть неразделенный по фазам сигнал ЯКР около 1.5–2.2 МГц; его принадлежность этим расчетом не устанавливается.

9. ФАЙЛЫ И ВОСПРОИЗВЕДЕНИЕ

Главные результаты: FINAL_MODEL_COMPARISON.csv, MODEL_ANALYSIS_RU.txt, powder_model_comparison.png/.pdf, exact_joint_refinements.json, central_control_results.json, central_exact_validation.json, joint_literature_sensitivity.json, central_extent_examples.json. CSV рядом содержат наблюдаемые и рассчитанные значения с явной маской включения в fit.

Основные команды из этой папки:
python powder_fit.py --extended
python powder_fit.py --set publication2013
python joint_fit.py
python joint_literature_sensitivity.py
python refine_exact_joint.py
python central_control.py
python finalize_results.py
python finalize_controls.py

Для старых диагностических графиков: python validate_and_plot.py.
Для численного примера крыльев: python extent_examples.py.

Требуются NumPy, SciPy и Matplotlib. Папка data_analysis/export должна быть соседней с powder_model. Файлы library_*.npz и central_library_*.npz — воспроизводимый промежуточный кэш; их не требуется включать в пользовательский пакет. Все результирующие CSV/JSON сохраняют вычислительные знаки, которые не являются экспериментальной точностью.
