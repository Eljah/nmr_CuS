# Теоретический расчёт модельного ГЭП анилита

Этот каталог содержит полный вывод формул, исполняемые символьные проверки,
новый независимый численный расчёт и промежуточные данные. Расчёт выполнен
27 ноября 2026 года по сохранённой транскрипции AMCSD 0009376 — структуре
Koto–Morimoto для анилита Cu₇S₄.

## Что получено

Для каждой из пяти Cu-позиций вычислен периодический тензор модели точечных
зарядов. В базовом нейтральном варианте каждому Cu приписан пробный заряд
8/7 элементарного заряда, каждому S — −2. Ещё пять нейтральных сценариев
перераспределяют избыточные четыре положительные зарядовые единицы на один
полный Cu-орбит за раз. Эти сценарии характеризуют чувствительность модели;
они не являются экспериментально установленными состояниями окисления.

| Позиция | Знаковое G_ZZ, в численных единицах | η_pc | Относительный модуль G_ZZ, Cu2 = 1 |
|---|---:|---:|---:|
| Cu1 | −0,30264647 | 0,55719893 | 0,68774730 |
| Cu2 | 0,44005476 | 0,05914175 | 1,00000000 |
| Cu3 | 0,03883146 | 0,25468057 | 0,08824233 |
| Cu4 | 0,37291139 | 0,16291879 | 0,84742041 |
| Cu5 | 0,41868874 | 0,58492897 | 0,95144691 |

ГЭП Cu3 оказывается значительно меньше остальных во всех шести сценариях.
Это свойство сохраняется и для их выпуклых комбинаций при фиксированных
координатах; доказательство через норму тензора дано в теоретическом приложении.
Оно относится только к указанному семейству точечных зарядов.

Полный ядерный ГЭП зависит от электронной плотности около Cu, ковалентности,
экранирования и антиэкранирования. Эти вклады не восстановлены данным расчётом.
Поэтому η_pc и физическая η из модели экспериментального ЯМР — разные виды
результатов. Численная сходимость суммы Эвальда не устраняет ограничения
электростатической модели.

## Выводы до численного расчёта

Английский исходник [efg_derivation.tex](efg_derivation.tex) содержит следующие
переходы без пропуска коэффициентов:

1. Кулоновский потенциал → первая производная → гессиан
   `(3 r_a r_b − r² δ_ab)/r⁵`, его знак, симметрия и нулевой след.
2. Разложение `1/r = erfc(αr)/r + erf(αr)/r` → обе радиальные производные
   → коэффициенты A и B действительной части суммы Эвальда.
3. Фурье-потенциал → отрицательный множитель `−k_a k_b` в обратной части.
4. Ряд `erf(αr)/r` около ядра → положительный член удаления собственного
   вклада `+4 α³ z_self/(3√π) I`. След проверяется до коррекции округления.
5. Переход к главным осям, порядок по абсолютным значениям, формула η,
   ограничения зеркальной симметрии 4c и нулевой тензор идеального тетраэдра.
6. Операторы спина 3/2 → явная матрица квадрупольного гамильтониана 4×4
   → два блока 2×2 → собственные значения →
   `ν_NQR = |ν_Q| sqrt(1 + η²/3)`.
7. Зеемановский гамильтониан → переходы и веса поперечного РЧ-поля →
   усреднение по неориентированному порошку.
8. Теория возмущений для центрального перехода при η = 0, включая
   промежуточные сдвиги каждого состояния. Получено
   `δν_CT = 3 ν_Q²/(16 ν_Z) (1−cos²θ)(1−9 cos²θ)`.
9. Явное решение задачи одного эмпирического масштаба для частот:
   `a = Σ P_i ν_i / Σ P_i²`, где
   `P_i = |G_ZZ,i| sqrt(1 + η_pc,i²/3)`.

Различие принятого ГЭП и буквальной производной электрического поля оговорено:
используется гессиан **потенциала**; для `E = −grad φ` градиент E имеет
противоположный знак. Знаки собственных значений сохранены в файлах.

## Единицы

В коде заряд записан как `q_j = z_j e`, в арифметике используется безразмерный
`z_j`, расстояния выражены в ангстремах. Численный тензор имеет размерность
Å⁻³ при таком выборе единицы заряда. В прежних файлах та же конвенция иногда
названа `e/Å³ с опущенным кулоновским множителем`.

Перевод в СИ содержит **один** множитель элементарного заряда:

`V_pc [В/м²] = G_numeric × e/(4π ε0) × 10³⁰`.

Множитель равен приблизительно `1,43996454687 × 10²¹ В/м²` на численную
единицу. Это перевод единиц голого модельного решёточного тензора. Из него
не вычисляется абсолютная физическая частота ЯКР анилита.

## Низкочастотная гипотеза Cu3

Сначала использованы только четыре высокочастотные частоты ⁶³Cu ЯКР из
диплома: 11,97; 15,27; 16,18; 16,96 МГц. Для каждого из шести зарядовых
сценариев рассмотрены **все 24** взаимно однозначных сопоставления Cu1, Cu2,
Cu4, Cu5 этим четырём группам. По каждой перестановке найден один общий
масштаб a. Низкочастотный интервал 1,5–2,2 МГц в эту подгонку не включался.

| Зарядовый сценарий | Условная частота Cu3 при лучшем частотном сопоставлении, МГц | RMS невязка четырёх высоких частот, МГц |
|---|---:|---:|
| Равномерный Cu = 8/7 | 1,50291 | 0,5844 |
| Добавочный заряд на Cu1 | 3,51559 | 0,5922 |
| Добавочный заряд на Cu2 | 2,18006 | 0,3713 |
| Добавочный заряд на Cu3 | 1,97518 | 0,5229 |
| Добавочный заряд на Cu4 | 1,40027 | 0,8775 |
| Добавочный заряд на Cu5 | 1,45307 | 0,7256 |

Диапазон лучших по частотной невязке сопоставлений — около 1,40–3,52 МГц;
диапазон всех 144 комбинаций — около 1,35–3,52 МГц. Это модельная
чувствительность, а не доверительный интервал измеренной частоты.

В базовом варианте оптимально по частотам сопоставление
`s1,s2,s3,s4 → Cu1,Cu4,Cu2,Cu5`. Оно даёт масштаб
`38,29166696 МГц на численную единицу P` и частоту Cu3 `1,502909 МГц`.
Однако высокие частоты тогда равны 12,174; 14,342; 16,860; 16,922 МГц:
максимальная относительная невязка около 6,07%. Модельные η в этом
сопоставлении также не воспроизводят весь набор η из порошковой подгонки.
Поэтому результат формулируется как проверяемая гипотеза о вкладе Cu3,
а не уникальное кристаллографическое присвоение.

В дипломе низкочастотный сигнал показан для смешанного образца номинального
состава Cu₁․₁S при 4,2 К. Известен конкретный конкурирующий вклад: у CuS
опубликован дублет ⁶³Cu/⁶⁵Cu около 1,87/1,73 МГц при 4,2 К. Поэтому
весь исторический низкочастотный отклик нельзя приписать Cu3 анилита
только по положению в этом диапазоне. Подробная проверка диплома сохранена
отдельно в [LOW_FREQUENCY_SIGNAL_RU.md](../new_evidence/thesis/LOW_FREQUENCY_SIGNAL_RU.md).

## Воспроизведение

Из корня репозитория с Python 3 и установленными NumPy, SciPy и SymPy:

```bash
python theory/symbolic_algebra.py
python theory/export_efg_intermediates.py
python theory/validate_efg_intermediates.py
```

Символьные выкладки проверены с SymPy 1.14.0; фактическая версия
сохраняется в JSON. Версии Python, NumPy и SciPy численного расчёта
записаны в `results/efg/structure_and_conventions.json`.

Сборка теоретического PDF обычной установкой LaTeX:

```bash
cd theory
pdflatex -interaction=nonstopmode -halt-on-error efg_derivation.tex
pdflatex -interaction=nonstopmode -halt-on-error efg_derivation.tex
```

BibTeX для этого приложения не требуется. Два прохода обновляют оглавление
и перекрёстные ссылки. Основная статья и её библиография находятся отдельно
в `latex_article/`.

## Проверки, которые выполнены

Все 19 символьных тождеств пройдены. Независимый численный расчёт отличается
от прежнего тензора Эвальда не более чем примерно на 3,33 × 10⁻¹⁵ численных
единиц; изменение α даёт максимум около 2,44 × 10⁻¹⁵. Максимальный след до
коррекции округления — около 4,16 × 10⁻¹⁵. Повторное суммирование 80 700
сохранённых действительных и обратных вкладов воспроизводит экспортированные
подытоги и итоговые тензоры.

Эти проверки подтверждают алгебру, единицы и воспроизводимость численного
суммирования. Физическая достаточность модели проверяется отдельно по
эксперименту и расчёту электронной структуры.
