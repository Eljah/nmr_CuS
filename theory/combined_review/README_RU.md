# Сводный расчётный блок и научные графики

Основной документ: [REPORT_RU.md](REPORT_RU.md).
Он объединяет результаты трёх новых физических модулей и объясняет,
какие гипотезы ограничены данными, а какие ещё не различаются.

## Сборка в IntelliJ / Windows 10

Распакуйте весь комплект, сохранив каталоги theory и его подкаталоги.
Откройте theory/pom.xml как Maven-проект в IntelliJ IDEA. Выберите
Project SDK 17 или более новый полноценный JDK и Maven Runner с тем же
JDK. В проект входят шесть модулей; Gradle не требуется.

Из корня комплекта или репозитория:

~~~powershell
mvn -B -f theory/pom.xml package
java -jar theory/combined_review/target/combined-review-1.0.0.jar
~~~

Последняя команда перерисовывает сохранённые результаты, не запускает
новую подгонку. Она не требует подключения к GitHub. При первоначальной
сборке Maven загружает плагины и библиотеку графиков.

Для работы из другого каталога передайте корень комплекта явно:

~~~powershell
java -jar C:\work\nmr_CuS\theory\combined_review\target\combined-review-1.0.0.jar C:\work\nmr_CuS
~~~

В Linux/macOS команды те же, с обычными прямыми разделителями путей.
В каталоге этого модуля доступны также run.cmd и run.sh.

Пять физических Java-модулей не требуют внешней численной библиотеки.
Модуль графиков использует XChart 3.8.8, включённый в итоговый JAR через
Maven Shade. Старые независимые аудиты на Python сохранены в своих
каталогах; их наличие не требуется для запуска новых Java-программ.

Исходные данные новых модулей скопированы внутрь каждого из них вместе
с происхождением и контрольными суммами. Полный многомодульный комплект
не равен всему исследовательскому архиву: большие исходные вложения и
старые бинарные библиотеки доступны в полном Git-репозитории.

## Что делает генератор

Программа читает уже сохранённые CSV, проверяет число столбцов,
строит PNG и SVG и записывает SHA-256 использованных таблиц в
figures/PROVENANCE.json. Она не подгоняет параметры и не меняет
исходные частоты, скорости или спектры.

| График | Содержание и смысл линий |
|---|---|
| nqr_temperature | Архивные частоты и общий Bose-fit; модель в пропуске не является измерением |
| tensor_harmonic_direction | Направление пары коэффициентов (B,F), не угол атомных смещений или осей ГЭП |
| r1_over_t | Архивный R₁/T, соединения точек только для чтения; погрешности имеют исходную конвенцию |
| r1_over_t_low_temperature | Та же величина до 80 K на линейной вертикальной шкале |
| bpp_parameter_profile | Профиль критерия по log₁₀τ₀; допуск 1% является описательным |
| nmr_comparison_500ms / 20ms | Три модели и измеренные спектры; исключённые точки отмечены отдельно |
| nmr_comparison_fullscale_500ms / 20ms | Полная вертикальная шкала, включая высокие маскированные приборные пики |
| nmr_residuals_500ms / 20ms | Остатки на использованных точках в той же нормировке |

Нормировка каждого ЯМР-спектра использует максимум его сохранённых
измеренных точек, прошедших маску. Внешний вид графика не заменяет
сводный численный критерий совместной подгонки двух спектров.
Основные сравнения увеличены до диапазона −0.02…1.06; более высокие
маскированные приборные пики видны на версиях fullscale. Их значения
сохранены во всех исходных таблицах.

Шрифты и растеризация зависят от операционной системы: PNG/SVG могут
не совпадать побайтно при повторном построении. Исходные CSV и их
контрольные суммы позволяют отличить изменение данных от оформления.

## Проверки

Общая сборка всех шести модулей фактически выполнена с JDK 17.0.17+10
и Maven 3.9.11. [BUILD_VALIDATION.json](verification/BUILD_VALIDATION.json)
фиксирует совместимость Java 17, контрольные результаты и проверку
входов графиков; [журнал Maven](verification/maven_build.log) сохраняет
успешный результат всей сборки.

Сборка использует release 17. Физические модули сохраняют собственные
аналитические и численные проверки, включая синтетические тензоры,
известные решения ограниченного МНК, пределы BPP и независимые
собственные значения спинового гамильтониана. Генератор визуально
проверен по конечным PNG; самостоятельные тесты, повторяющие его
рисование, не добавлялись.

Основная граница интерпретации: согласие алгоритма с формулами не
устанавливает уникальную структуру и не заменяет оценку
экспериментальных погрешностей.
