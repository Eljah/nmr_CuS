# Релаксация и динамические гипотезы по архивным данным ЯКР

Самостоятельный проект Java 17/Maven без сторонних расчётных библиотек.
Работает с сохранёнными параметрами релаксационных кривых диплома 2009 года.
Исходные кривые восстановления намагниченности M(t) в этих таблицах отсутствуют.

Основной результат: [аналитический отчёт](outputs/ANALYSIS_RU.md).
Машиночитаемый итог: [SUMMARY.json](outputs/SUMMARY.json).

## Воспроизведение в Linux/macOS

Нужны полноценный JDK 17 или новее и Maven 3.9+. Сборка использует
--release 17. Запускать из каталога данного модуля:

~~~sh
cd theory/relaxation_dynamics
mvn -B clean package
java -jar target/relaxation-dynamics-1.0.0.jar --self-test
java -Xmx512m -jar target/relaxation-dynamics-1.0.0.jar
~~~

Последняя команда проверяет SHA-256 входных файлов, выполняет смысловые
численные проверки и пересчитывает CSV/JSON. Случайных запусков нет.
Maven собирает приложение; самостоятельные численные проверки запускаются
явно флагом --self-test и автоматически перед каждым полным расчётом.

## Воспроизведение в Windows PowerShell

~~~powershell
Set-Location theory\relaxation_dynamics
mvn -B clean package
java -jar target\relaxation-dynamics-1.0.0.jar --self-test
~~~

Не требуется Python, Bash или вычислительный код на другом языке.
Можно явно передать абсолютный путь к модулю:

~~~powershell

~~~

## Источники и материализация

Входные CSV, исходные column_provenance.json, PDF и TXT диплома уже
сохранены внутри inputs. Обычный пересчёт не обращается к Git или сети.
inputs/manifest.json указывает исходную Git-ревизию и пути;
inputs/manifest.sha256 проверяется при каждом пересчёте.

Для осознанного обновления входов из текущего HEAD исходного репозитория:

~~~sh
java -jar target/relaxation-dynamics-1.0.0.jar --materialize
~~~

Эта отдельная команда копирует исходники через git show байт-в-байт и
обновляет манифест только внутри данного модуля. Не запускайте её просто
для воспроизведения сохранённого результата на другой ревизии.
inputs/isotope_observations.csv — явная ручная транскрипция четырёх
скоростей со страницы 27 PDF; две ошибки 65Cu в источнике отсутствуют.
Исходники не заменяются исправленными таблицами: исключения и конфликтующие
версии перечислены отдельно в выходных таблицах.

## Модели и критерий

Для R1 на T≥50 K сравниваются:

1. linear_T: R1_i = a_i T, 4 параметра.
2. shared_theta: R1_i = a_i T + B_i exp(−Θ/T), 9 параметров.
3. separate_theta: та же форма с Θ_i, 12 параметров.
4. shared_power: R1_i = a_i T + C_i(T/250)^p, 9 параметров.

Чтобы не подгонять огромные B напрямую, экспоненциальный член записан как
C_i exp[−Θ(1/T−1/250)]. Тогда B_i=C_i exp(Θ/250).
Все a_i,C_i неотрицательны; Θ∈[0,16000] K, p∈[1.2,24].
Линейные коэффициенты исключаются точно ограниченным МНК, затем полная
сетка и локальное уточнение профилируют нелинейный параметр.

Основной критерий:

S = Σ[(R_model−R_observed)/s]².

В первом варианте s=ErrW1. Это сохранённый масштаб погрешности, а не
установленное стандартное отклонение. В проверке чувствительности
s=max(ErrW1,0.05 R1). Ни один S не объявляется χ² с известным распределением.

Прогноз проверяется двумя раздельными схемами:

- **Interleaved:** уникальные T сортируются; номер температуры modulo 4
  задаёт fold. Все позиции при одном T удерживаются вместе.
- **Contiguous:** отсортированные уникальные T делятся на четыре
  непрерывных диапазона. Эта проверка включает экстраполяцию за пределы
  обучающего температурного диапазона.

В файлах activation_comparison.csv и activation_predictions.csv столбцы
heldout_* означают только первую схему. Непрерывные диапазоны вынесены в
activation_contiguous_cv_*. Обе схемы для степени явно названы в power_*.

BPP — дополнительная феноменологическая модель одной лоренцевой
спектральной плотности. Это не точный расчёт восстановления четырёх
спиновых уровней и не установление конкретного механизма релаксации.

## Существенные границы интерпретации

- T1T в obj03 — R1/T, а не T1·T. Это повторное представление obj04.
- Частотные ветви 65Cu получены делением 63Cu на 1.081.
- Одинаковый блок R2(s3,s4) при 180–230 K не даёт двух независимых
  свидетельств. Анализ исключает обе метки либо сохраняет только s3.
- Основная интерполяция ν не пересекает промежутки больше 30 K.
  Отдельная 75 K проверка намеренно перекрывает отсутствие ν_s4 между
  160 и 230 K; её нельзя называть измеренной частотной зависимостью.
- Близость CuS и s-линий сохранена отдельно и сама по себе не
  предполагает пространственный контакт разных фаз.
- Подгонка экспонентой или степенью не доказывает CDW, миграцию Cu,
  фононный механизм или псевдощель. Значения энергии здесь модельные.
- Аналитический отчёт относится к сохранённому снимку входов. При их
  обновлении следует заново проверить его численные выводы по CSV/JSON.
