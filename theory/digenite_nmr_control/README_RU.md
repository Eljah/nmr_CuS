# Совместный контроль аксиальности локальных ГЭП

В этом расчёте все четыре спектроскопические группы s1–s4 имеют фиксированное
`eta = 0`. Измеренные частоты ЯКР сохранены. Это проверка аксиальности локальных
ГЭП в принятой семье моделей ЯМР; частоты и заселённости конкретной атомной
структуры дигенита здесь не предсказываются.

## Итоговые файлы

- `comparison.csv` — критерий и RMS, включая отдельные серии 500 и 20 ms.
- `parameters.csv` — параметры четырёх групп и их амплитуды.
- `summary.json` — компактные результаты, все границы и определения.
- `FINAL_CONTROL.json` — уточнения, проверка угловой квадратуры и контроль
  неизменности архивных входных файлов по SHA-256.
- `axial_exact1280_500ms.csv`, `axial_exact1280_20ms.csv` — предсказания
  аксиальной модели и остатки на исходных частотах.
- `archived_free_eta_seed67_exact160_500ms.csv` и соответствующий файл 20 ms —
  предсказания лучшей из двух архивных ветвей свободных eta.

## Общая модель и критерий

Использованы исходные частотные интегралы `data_analysis/export/opj_Spec05122016.csv`.
Две записи на 81.40 MHz исключены. Маски вокруг 75.941 и 81.346 MHz имеют
полуширину 0.12 MHz. Остаётся по 245 точек, всего 490.

В каждой серии интенсивность делится на максимальную наблюдаемую интенсивность
вне масок. Минимизируется сумма квадратов нормированных остатков обеих серий:

`E = sum_r sum_i_used ((prediction[r,i] - observation[r,i])/Y[r])**2`.

Это описательный критерий, а не калиброванный chi-square. RMS равен
`sqrt(E/N)` для соответствующего набора точек.

Все переходы рассчитываются точной диагонализацией гамильтониана спина 3/2
с теми же поперечными RF-весами, что в архивном `powder_model/powder_fit.py`.
Для каждой группы задан свободный изотропный эффективный Zeeman-центр
63Cu в пределах 74.8–76.8 MHz; центр 65Cu связан с ним постоянным
гиромагнитным отношением. Общая Gaussian sigma ограничена 0.025–0.25 MHz.
Для каждой серии отдельно оптимизируется относительный вес 65Cu в пределах
0.05–0.8. Параметры центров и ширины общие для двух серий.

ЯКР используется как жёсткое ограничение
`nuQ = nuNQR/sqrt(1+eta**2/3)`, без штрафа за экспериментальную ошибку ЯКР.
Набор 63Cu: 11.97, 15.27, 16.18, 16.96 MHz; набор 65Cu: 11.07, 14.13,
14.97, 15.69 MHz.

При каждой нелинейной итерации заново находятся четыре неотрицательные
амплитуды и два свободных коэффициента линейной поправки для каждой серии.
Поправка имеет вид `b0 + b1*(frequency_MHz-78)/6` и может быть отрицательной.
В модели свободных eta номинально 11 нелинейных + 12 линейных = 23 параметра;
в аксиальном контроле — 7 + 12 = 19. Эти числа не трактуются автоматически
как статистические степени свободы при ограничениях NNLS и возможной
неидентифицируемости параметров.

## Поиск и воспроизведение

Запуск из корня репозитория, в Python с NumPy, SciPy и Matplotlib:

```bash
python theory/digenite_nmr_control/axial_control.py
python theory/digenite_nmr_control/refine_axial_convergence.py
python theory/digenite_nmr_control/summarize_control.py
```

Первый скрипт выполняет три независимых поиска DE + Nelder–Mead по готовой
библиотеке и три уточнения прямым гамильтонианом на сетке 80×160. Второй
проверяет аксиальную симметрию и сходимость по cos(theta), уточняет результат
на 640 точках и выполняет дополнительный прямой глобальный поиск.
Финальная аксиальная оценка использует 1280 точек cos(theta). При eta=0 и
изотропном сдвиге азимутальная зависимость отсутствует; равенство с полными
80×160 и 160×320 сетками проверено численно. Архивные свободные-eta решения
сравниваются после прямой оценки на сетке 160×320 и повторного решения
линейных параметров. Нелинейные параметры архивных решений не изменяются.

## Пределы интерпретации

В проверенной семье моделей одновременное условие eta=0 для всех четырёх групп
ухудшает описание. Достоверность этого различия не выражается через p-value
или доверительный интервал: модель экспериментального шума и корреляций
не задана.

Контроль не устанавливает отдельно, что eta_s3 или eta_s4 отличны от нуля:
для этого нужны отдельные условные профили с переоптимизацией остальных eta.
Не учтены анизотропный магнитный сдвиг K, распределения ГЭП, различающиеся
ширины отдельных групп, реальный профиль импульсного возбуждения и возможные
дополнительные фазовые компоненты. Свободная знакопеременная линейная
поправка может компенсировать недостатки спектральной модели.

Все новые файлы находятся в этом каталоге. Архивные скрипты, данные и
результаты сохранены без изменения; их контрольные суммы включены в JSON.
